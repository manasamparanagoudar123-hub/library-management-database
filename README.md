#  Library Management Database

A simple Library Management Database project created using MySQL.

##  Features

- Add student information
- Store book information
- Search books
- Check book availability
- Record borrowed books
- Record returned books
- View borrowing details
- Update book availability

## Technology Used

- MySQL
- SQL

##  Database Tables

### 1. Students
Stores student information such as:
- Student ID
- Student Name
- Department
- Email

### 2. Books
Stores book information such as:
- Book ID
- Book Name
- Author
- Category
- Availability

### 3. Borrowing
Stores borrowing details such as:
- Borrow ID
- Student ID
- Book ID
- Borrow Date
- Return Date

## SQL Concepts Used

- CREATE DATABASE
- CREATE TABLE
- INSERT
- SELECT
- UPDATE
- DELETE
- WHERE
- JOIN
- PRIMARY KEY
- FOREIGN KEY
- AUTO_INCREMENT

##  How to Run

1. Open MySQL.
2. Open the `library_management.sql` file.
3. Copy and execute the SQL commands.
4. The database and tables will be created.
5. Run the SELECT queries to view the data.
